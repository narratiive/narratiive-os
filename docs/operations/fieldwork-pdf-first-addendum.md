# Fieldwork v7.3 — PDF-first handback operating amendment

Matt's instruction of 6 November 2026 supersedes only the mandatory editable-PPTX
parts of v7.2. The exact PDF Matt explicitly approves is the authoritative
client-facing Fieldwork deliverable. Editable PPTX is optional internal source
material; its absence must not block eligible PDF adoption or PDF delivery.
This amendment does not change Sketchbook, Launchpad or any other deliverable's
editable-file requirements, nor the upstream strategy/evidence quality standard.

Retain the actual PDF, identity, version, producer, source provenance, checksum,
known QA findings and complete remaining required output bundle. Optional PPTX
must be identified as source material and validated if supplied. Filenames are
not approval evidence. Retain previous files and approvals; substantive PDF
changes need a new version and Matt's renewed exact-document decision.

Existing eligibility and approval gates remain unchanged. External adoption is
supported only at an already blocked final-preparation stage. An upload records
a candidate, not approval. The existing exact-human manual-recovery decision
remains mandatory before adoption. A completed approved engagement is not
reopened by this amendment. The current Origin fictional Fieldwork completion
has no supported authenticated supervised-revision operation; report that gap
rather than manufacturing a blocker or reusing an earlier approval.

Only the exact approved PDF is included by default in the existing governed
Drive delivery-preparation action. Optional source files are retained internally.
An internal email draft remains unsent; document approval does not authorise a
client email, publication, payment or any other external communication. Those
require their existing separate exact-action authorisation and evidence.

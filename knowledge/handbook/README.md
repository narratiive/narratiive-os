# Narratiive Handbook

The Narratiive Handbook is the canonical home for Narratiive-owned strategic models, principles and reusable intellectual property.

It sits inside Narratiive OS because knowledge is a component of the operating system, not a separate system.

## Agent use

Tony, Claude, Codex and specialist agents should use active Handbook models when their assigned work requires strategic judgement. Product-specific canon and evidence rules always take precedence where applicable.

Before strategic generation:

1. Read repository governance from `AGENTS.md`.
2. Resolve the relevant product canon and workflow contract.
3. Read the active models in this folder that apply to the task.
4. Preserve evidence lineage and distinguish Narratiive doctrine from external source evidence.

## Model naming

Narratiive-owned models use stable IDs so they can be referenced across Blueprints, Campaign Worlds, research, content and future software:

- N01 — Signal → Story → System → Scale
- N02 — Growth Flywheel
- N03 — Attention Ladder
- N04 — Narrative Gap
- N05 — Strategic Compounding
- N06 — Category Gravity
- N07 — Distinctiveness Scorecard
- N08 — Growth Friction Audit
- N09 — Campaign Momentum
- N10 — Evidence Pyramid

A model is not canonical merely because its filename exists. Each model must clearly state its status and version. Draft models may be tested but must not be represented externally as established Narratiive doctrine until approved.

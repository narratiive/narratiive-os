# Rave workflow comparison after the founder-argument repair

This assessment preserves the original Rave benchmark. It does not overwrite or reinterpret the original Claude strategy as a production artefact.

| Dimension | Original direct-Claude benchmark | Previous Tony schema-first route | Experimental founder-argument gate |
|---|---|---|---|
| Commissioning order | Strategic argument first | Presentation structure and fields first | Strategic argument first; presentation forbidden until approval |
| Coherence | One central argument carries the work | Insight fragments compete for attention | Five moves form one decision sequence |
| Commercial logic | Strong strategic direction, with some claims requiring verification | Mechanisms can be filled as isolated fields | Explicit growth mechanism, bounded levers and scenario-not-forecast control |
| Audience opportunity | Integrated into the strategic thesis | Often becomes another required section | Mandatory and tied to the commercial opportunity |
| Evidence use | Persuasive but less formally governed | Classified, but completion can dominate judgement | Classified references must support each founder-facing move |
| Founder usefulness | High narrative confidence | Technically complete but less decisive | Each move names the consequence and founder decision |
| Quality control | Human editorial judgement | Gate could be bypassed by missing fields | Missing fields fail closed; editorial QA is separate and explicit |
| Production state | Preserved benchmark only | Existing production path remains available | Opt-in experiment; awaiting human approval; no presentation handoff |

## Finding

The quality loss occurs before slide design: schema completion divides the reasoning into deliverable-shaped fragments before a single commercial argument has been established. The smallest effective repair is therefore a terminal, opt-in argument gate—not a new presentation system.

The accepted Rave experiment is materially closer to the original benchmark because it carries one claim through current position, commercial opportunity, growth levers, audience opportunity and strategic direction. It is also more governable: evidence lineage, editorial checks, scenario language and the human stop are machine-inspectable.

## Remaining judgement

One successful Rave execution is evidence of viability, not proof of general quality. Before promotion to the production default, run the same gate against at least two unlike founder-led businesses and have Matt compare the blinded outputs for insight, confidence and usefulness. Current Rave evidence must be revalidated before any client-facing use.

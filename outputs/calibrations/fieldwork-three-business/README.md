# FIELDWORK three-business candidate calibration

This internal evidence pack calibrates the opt-in founder-argument gate against Rave Coffee, KatKin and The Yardstick Agency.

Start with:

- `three-business-comparison.md` for the commercial comparison;
- `candidate-production-contract.md` for the proposed workflow boundary;
- `client-design-system-specification.md` for shared and client-specific design rules;
- `editorial-and-visual-scorecard.json` for the comparable 1–5 review rubric;
- `validation-evidence.md` for live provider receipts, fail-closed behaviour and test results.

Each business directory contains the public research case, accepted founder argument,
strict quality result, execution receipt, evidence-and-assumptions register and
five-slide editable/review outputs. All exercises are unsolicited, internal and
unapproved. No business was contacted.
